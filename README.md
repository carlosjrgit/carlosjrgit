### 🚀 Sobre Mim

- 💻 **Desenvolvedor de Software e Educador**, focado na criação de ferramentas desktop práticas, utilitários e automações.
- ⚙️ Desenvolvimento de **Aplicações Desktop (GUI & CLI)** com interfaces modernas, responsivas e arquitetura modular.
- ⚡ Experiência prática com **multithreading e processamento assíncrono**, garantindo execução fluida sem travamento de interface gráfica.
- 🤖 Automação de processos, web scraping e integração com APIs com tratamento estruturado de dados.
- 🧠 **Desenvolvimento Assistido por IA (AI-Assisted Development)** e uso de **Agentes de IA** aplicados à automação de workflows e engenharia de software.
- 🛡️ Foco em **segurança defensiva**, validação rigorosa de entradas (prevenção de path traversal e injeções), **Clean Code** e logging estruturado.

### 🧰 CJR Tools

**CJR Tools** é uma coleção autoral de utilitários e aplicações desktop desenvolvidos com foco em automação, produtividade, processamento local e segurança de software. Projetados seguindo princípios de arquitetura modular, interfaces intuitivas (GUI & CLI) e distribuição simplificada via GitHub Releases.
